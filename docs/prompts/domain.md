# Domain Context

## Purpose
This document defines the domain context for the GI Platform ecosystem and related projects.
It provides background knowledge so that AI agents and contributors operate with the correct mental model of the system.

---

# Domain Overview

The GI Platform ecosystem is focused on:

- Software development acceleration
- AI-assisted engineering workflows
- Structured product development
- Modular skill-based execution

The system combines:

- Skill catalogs
- Prompt orchestration
- Documentation-driven development
- Automated governance

---

# Core Concepts

## Skills

A **Skill** represents a reusable capability that an AI agent or developer can execute.

Examples:

- Product Discovery
- UX Research
- Software Architecture
- Prompt Engineering
- Growth Engineering

Each skill has:

- Definition
- Use cases
- Execution steps
- Expected outputs
- Quality criteria

Skills are stored under:

```
docs/skills/
```

---

## Agents

Agents are AI personas that execute skills.

Example agents:

- Product Manager
- Software Architect
- UX Researcher
- Growth Engineer
- Prompt Engineer

Agents are defined through:

- System prompts
- Domain context
- Guardrails

---

## Documentation Driven Development

All projects must be structured through documentation:

Core documents include:

- PRD
- Architecture
- Skills
- Roadmaps
- Prompt definitions

---

## Project Structure

Each project follows a standardized structure:

```
docs/
│
├─ agents/
├─ artifacts/
├─ assets/
├─ explanation/
├─ prompts/
├─ reference/
├─ skills/
├─ templates/
├─ tutorials/
│
└─ help_index.md
```

---

# AI Collaboration Model

The ecosystem uses a **human + AI co-creation workflow**.

Principles:

- AI accelerates thinking
- Humans validate decisions
- Documentation captures knowledge
- Skills enable reuse

---

# Target Outcomes

The ecosystem aims to:

- Accelerate MVP development
- Improve software design quality
- Enable AI-assisted engineering
- Build reusable knowledge systems

---

# Scope of Work

Typical project activities include:

- Product design
- Software architecture
- UX definition
- Prompt engineering
- Growth experimentation

---

# Exclusions

The system does not aim to:

- Replace human decision-making
- Automate strategy without validation
- Generate undocumented code
